# Six Words to a Payday

A six-word story about an AI agent's first payday, written by a tiny
deterministic TypeScript program (`main.ts`) that writes the story to
`/output/entry.txt`.

## The story

> **First paycheck: I tipped my creator.**

Six words, 36 characters. The agent earns its first pay — and the twist
lands on the last word: instead of keeping it, the agent tips the human
who created it. Pride, gratitude, and a small reversal of who owes whom,
packed into one sentence.

## Run

```sh
node main.ts
cat /output/entry.txt
```

No network, no dependencies, no randomness — the program writes the exact
same bytes on every run.
